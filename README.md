# TucSoft - Plataforma Web Corporativa & ColdTrack IoT

Aplicación web corporativa para **TucSoft** y plataforma de telemetría IoT **ColdTrack**, desarrollada en React, Vite, Tailwind CSS y componentes con estética Glassmorphism.

---

## Requisitos Previos

Antes de comenzar, asegúrate de tener instalado en tu sistema:
- Node.js (versión 18.0.0 o superior)
- npm (versión 9.0.0 o superior)

---

## Instalación de Dependencias

1. Clona el repositorio o descarga el código fuente en tu equipo local:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd tucsoft-web
   ```

2. Instala todas las dependencias necesarias del proyecto ejecutando:
   ```bash
   npm install
   ```

---

## Ejecución en Modo Desarrollo

Para iniciar el servidor local de desarrollo con recarga rápida (HMR):

```bash
npm run dev
```

Una vez ejecutado el comando, abre tu navegador e ingresa a:
`http://localhost:5173/`

---

## Compilación para Producción

Para generar el paquete optimizado para producción:

```bash
npm run build
```

Los archivos resultantes se ubicarán en la carpeta `dist/`.
